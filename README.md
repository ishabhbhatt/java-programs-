 # Java Practical Programs

## About This Repository

This repository contains 7 Java practical programs developed as part of my college programming coursework. These programs cover the fundamental concepts of Core Java, including programming constructs, arrays, strings, object-oriented programming, inheritance, exception handling, multithreading, and file handling.

The programs are written using simple logic and beginner-friendly coding practices to make them easy to understand, execute, and modify.

## Programs Included

| No. | Practical Name | Concepts Covered |
|---|---|---|
| 01 | Fundamental Programming Constructs | Variables, operators, input/output, if-else, loops |
| 02 | Array and String Processing | Arrays, string methods, searching and basic calculations |
| 03 | Classes, Objects, Constructors and Methods | Object-oriented programming fundamentals |
| 04 | Inheritance and Interface-Based Design | Inheritance, interfaces, extends and implements |
| 05 | Exception Handling and Custom Exceptions | try-catch, finally, throw, throws and custom exceptions |
| 06 | Multithreading and Thread Synchronization | Threads, synchronization, wait(), notify() and join() |
| 07 | File Processing Using Streams and Reader-Writer Classes | File reading, writing, BufferedReader and BufferedWriter |

## Technologies Used

- **Programming Language:** Java
- **JDK:** Java Development Kit
- **IDE:** VS Code / IntelliJ IDEA / Eclipse
- **Platform:** Windows

## How to Run the Programs

**Step 1:** Install Java JDK on your computer.

**Step 2:** Download or clone this repository.

```bash
git clone YOUR_REPOSITORY_LINK
```

**Step 3:** Open the project folder in VS Code or Command Prompt.

**Step 4:** Compile the Java file.

```bash
javac 01_FundamentalConstructs.java
```

**Step 5:** Run the program.

```bash
java FundamentalConstructs
```

Follow the same process for the remaining programs using their respective file and class names.
